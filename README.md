 ✨ **AI Smart Calculator**

A modern futuristic calculator website built using **HTML, CSS, and JavaScript** with a premium glassmorphism UI design.


 🚀 **Features**

 Basic Calculator Operations

  * Addition
  * Subtraction
  * Multiplication
  * Division

 Scientific Features

  * Percentage (%)
  * Square Root (√)
  * Square (x²)

  Modern UI Design

  * Glassmorphism Effect
  * Neon Glow Display
  * Animated Background Blur
  * Responsive Layout

 Interactive Effects

  * Hover Animations
  * Button Press Effects
  * Floating Animation

 Keyboard Support

  * Enter → Calculate
  * Backspace → Delete
  * C → Clear


 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
